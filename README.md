# Narayan Dynamics Services

Professional static website for Microsoft Dynamics 365 Finance & Operations consulting services.

## GitHub Pages deployment

1. Create a GitHub repository named `NarayanDynamicsServices`.
2. Upload `index.html` and `style.css` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will publish the site at:
   `https://YOUR-GITHUB-USERNAME.github.io/NarayanDynamicsServices/`

### Custom domain later
A purchased domain such as `narayandynamicsservices.in` can be connected to GitHub Pages so the GitHub URL does not appear in the public address.
